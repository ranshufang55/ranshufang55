# Huang Zeyao

I'm a student at **Sun Yat-sen University**, working on audio visualization and speech language models.

I build tools that make audio easier to inspect and speech model experiments easier to reproduce.

## Projects

| Project | Focus | Stack |
| --- | --- | --- |
| [sonascope](https://github.com/ranshufang55/sonascope) | Audio analysis and an interactive browser workbench for waveforms, spectra, and spectrograms. | TypeScript, Web Audio, Canvas |
| [speechloom](https://github.com/ranshufang55/speechloom) | Audio-text dataset preparation, speech model evaluation, and reproducible comparison reports. | Python |

## Interests

- Signal processing and interactive audio visualization
- Speech language models and audio-text interfaces
- Reproducible evaluation, dataset quality, and streaming behavior

## Working with the projects

Each repository includes its own setup instructions, tests, and runnable examples.
The examples use small, reproducible inputs so the basic workflows can be explored locally.

For questions about a project, please open an issue in its repository with a small example that reproduces the problem.
